# 🌷 Transaction Categoriser App

A decision-logic application built for Windows 11 that automatically categorises purchase descriptions into spending groups (Groceries, Transport, Utilities, and Other Spending) with Rand (R) currency formatting.

---

## 💕 Key Features

* **Dual Interface (Single File):** Features Terminal CLI mode and Desktop GUI App mode in a single script.
* **Keyword Matching:** Evaluates item descriptions using conditional `if / elif / else` logic branches.
* **Full Explicit Variable Naming:** Written strictly using un-abbreviated variable names (`customer_name`, `amount`, `category`, `transaction_list`).
* **Custom Styled Alerts:** Replaces native OS alerts with custom `Toplevel` pop-up dialogs.
